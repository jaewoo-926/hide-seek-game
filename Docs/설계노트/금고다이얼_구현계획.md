# 금고 다이얼 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 금고 다이얼 미니게임(3단계, 등급별 구간)을 온라인 인게임에 넣고, 전체 창(E)과 작은 다이얼(R) 두 화면으로 비교할 수 있게 한다.

**Architecture:** 판정은 순수 C# `SafeDial`(별도 asmdef, EditMode 테스트), 화면은 `ISafeDialView`를 구현한 uGUI 프리팹 2종, 연결은 로컬 플레이어의 `SafeDialController`, 서버 상태는 `OnlineGame`이 시드로 등급·목표를 만들고 진행 단계·사용 중을 동기화한다.

**Tech Stack:** Unity 6000.6.5f1, Netcode for GameObjects 2.13.3, Input System 1.20, uGUI 2.6, Unity Test Framework 1.8 (NUnit)

**Spec:** `Docs/설계노트/금고다이얼.md`

## Global Constraints
- 인게임 파일만 수정: `Assets/Chase/Scripts/*.cs`, `Scripts/Online/*`, `ChaseOnline` 씬, `OnlineGame`/`OnlinePlayer` 프리팹, 새 `Assets/Chase/Scripts/SafeDial/`, `Assets/Chase/Tests/`, `Assets/Chase/Prefabs/UI/`, `Assets/Chase/Editor/`. 로비(`Scripts/Network/*`, Title/Lobby 씬, LobbyPlayer)는 건드리지 않는다.
- 변수명은 엑셀 '변수명 정리' 이름: `safeDialTicks`, `safeDialSteps`, `safeDialSpeed`, `safeFailLockSec`, `safeDialSoundRange`, `gaugeMaxAmount`, `safeCount`.
- 값: 눈금 100, 단계 3, 30칸/초, 잠금 1초, 소리 5m, 구간 4/3/2, 금액 1000/2000/4000, 개수 6/4/2, 게이지 13000.
- 오른쪽 = 눈금 감소. 방향 순서 오른쪽 → 왼쪽 → 오른쪽.
- 커밋은 사용자가 요청할 때만, `feature/ingame-prototype`에만. `ClaudeBridge/`, 의도치 않은 `ProjectSettings` 변경은 빼기.
- 문자열·주석은 한국어.

## Review Focus
1. 목표 눈금이 0 근처(예 98, 1)일 때 구간이 양쪽으로 제대로 생기는지 → Task 1 테스트 `Hit_WrapsAroundZero`.
2. 방향을 반대로 돌린 상태로 구간에 들어가면 띡·확정 모두 안 되는지 → Task 1 테스트 `WrongDirection_NoTickNoHit`.
3. 두 도둑이 같은 금고를 동시에 열려고 할 때 한 명만 열리는지 → Task 2 검증 3.
4. 창이 열린 채 곤봉에 맞거나 체포될 때 창이 닫히고 진행 단계는 남는지 → Task 2 검증 4, Task 4 검증.
5. 확정 직후 서버 응답 전에 또 Space를 눌러도 단계가 두 번 오르지 않는지 → Task 2 검증 2(같은 단계 중복 요청 거절) + Task 4 `awaiting` 처리.

```csharp
public enum DialDirection { Right = -1, Left = 1 }      // 값이 변하는 부호
public enum ConfirmResult { Hit, Miss, Locked, Done }
public sealed class SafeDial {
    public const int Ticks = 100, Steps = 3;
    public SafeDial(int[] targets, int zone, int step, float speed = 30f, float failLockSec = 1f);
    public float Value { get; }            // 0 이상 100 미만
    public int Tick { get; }               // 반올림 % 100
    public int Step { get; }               // 0..3
    public bool IsOpen { get; }            // Step >= 3
    public DialDirection Direction { get; }// Step 1 만 Left
    public bool InZone { get; }            // 마지막 회전 방향이 Direction 과 같고 Hit(Tick)
    public double LockedUntil { get; }
    public event System.Action EnteredZone, Failed;
    public void Rotate(float ticks, double now);   // 부호 = 방향. 잠금 중 무시. |ticks|>0 일 때만 lastDir 갱신
    public void RotateByInput(float axis, float dt, double now); // axis(-1..1, +1=오른쪽) * speed * dt → Rotate(-axis*speed*dt)
    public ConfirmResult Confirm(double now);      // Locked/Done/Hit/Miss. Miss 면 LockedUntil=now+failLockSec, Failed
    public void SetStep(int step);                 // 서버 동기화 값 반영
    public static int Distance(int a, int b);      // 원형 거리
    public static bool IsHit(int tick, int target, int zone); // Distance <= zone
}
```
