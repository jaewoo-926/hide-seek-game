# 금고 다이얼 설계 (2026-11-21)

자세한 설명과 그림: `금고다이얼_구현설명_정재우.pdf` (Downloads). 이 문서는 구현 기준이 되는 결정만 적는다.

## 목적
기획 엑셀 '금고 미니게임'·'금고 등급' 시트의 다이얼 미니게임을 인게임(온라인)에 넣는다.
창 방식은 팀 회의에서 고르기 위해 **전체 창(E)** 과 **작은 다이얼(R)** 두 가지를 모두 만든다.

## 하지 않는 것
- 금고 후보 29곳 배치·MapMarker 연동 (지금처럼 아이템 후보 자리 사용)
- 최종 효과음·최종 이미지 (임시로 코드에서 만든 소리와 그림을 쓰고, 디자인 담당이 교체)
- 경찰 발소리

## 규칙 (엑셀 값)
| 이름 | 값 |
|---|---|
| safeDialTicks | 100 (0~99, 원형) |
| safeDialSteps | 3. 방향: 1단계 오른쪽, 2단계 왼쪽, 3단계 오른쪽 |
| safeDialSpeed | 30 칸/초 (A/D, ←/→). 마우스 좌우 드래그도 가능 |
| safeFailLockSec | 1 (구간 밖 확정 시 잠금) |
| safeDialSoundRange | 5 m (돌리는 소리가 경찰에게 들림) |
| 구간(±) | 소액 4, 중간 3, 고액 2 |
| 금액 | 소액 1000 ×6, 중간 2000 ×4, 고액 4000 ×2 (12개, 총 22000) |
| gaugeMaxAmount | 13000 |
| safeKeepProgress | true (닫아도 맞춘 단계 유지) |

- "오른쪽" = 시계 방향 = 눈금 값이 줄어드는 방향 (시안 영상: 0에서 오른쪽으로 돌려 72). D, →, 마우스 오른쪽 드래그가 오른쪽.
- 지금 방향과 다르게 돌리는 중에는 구간에 들어가도 "띡"이 나지 않고 확정해도 실패.
- 금고 재충전(45초)은 없앤다.

## 구조
- **판정** `SafeDial` — 일반 C# 클래스, 별도 asmdef(`Chase.SafeDial`)로 EditMode 테스트 가능. 화면·네트워크를 모른다.
- **화면** `ISafeDialView` + `SafeDialFullView`(E) / `SafeDialCompactView`(R). uGUI 프리팹, 판정 상태를 그리기만 한다.
- **연결** `SafeDialController` — 내 플레이어에 붙어 입력을 판정에 넘기고, 화면을 갱신하고, 서버에 요청을 보낸다.
- **네트워크** `OnlineGame` — 등급·금액·목표 눈금(시드로 동일 생성), 금고별 진행 단계, 사용 중인 사람, 확정 검사, 돈 지급.

## 네트워크 결정
- 돌리기는 내 화면에서만. 서버에는 열기·확정·닫기만 요청한다.
- 확정 요청은 (금고, 단계, 눈금)을 보내고 서버가 같은 목표 눈금으로 다시 검사한다.
- 서버는 곤봉에 맞음·기절·체포·감옥·라스트 타임·금고에서 멀어짐이면 사용 중을 비워 창을 강제로 닫는다.
- 한 금고는 한 명만. 다른 도둑이 열고 있으면 안내만 뜬다.

## 회의 비교용 (회의 후 삭제)
- E = 전체 창, R = 작은 다이얼. 진행은 공유.
- F10 = 빛 힌트(구간 안이면 현재 램프 노랑 + 테두리 금색). 기본 꺼짐(기획대로 소리·떨림만).

## 회의에서 정할 것
1. 창 방식 2. 빛 힌트 3. 기획·디자인 공유 4. 경찰 발소리 필요 여부
